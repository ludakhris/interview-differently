# Sample SCORM packages

Two tiny packages for trying SCORM import in LearnDifferently: a 3-question quiz
that reports its score and completion back to the player.

- `safe-lifting-scorm12.zip`: SCORM 1.2
- `forklift-basics-scorm2004.zip`: SCORM 2004

In a course, open a module and choose **+ SCORM package**, then pick a zip.
`make.py` rebuilds both (`python3 make.py`).
